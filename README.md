# UrbanEra Portfolio

Static client portfolio built from the public Google Drive project folder.

## Preview

Open `index.html` in a browser, or run a tiny local server from this folder:

```powershell
C:\Users\Admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.

## Free Hosting

Fastest free options:

- Cloudflare Pages: upload this folder or connect a GitHub repository.
- GitHub Pages: push this folder to a repository and enable Pages.
- Netlify: drag and drop this folder into a new static site.

The gallery currently uses Google Drive thumbnail links, so the site stays small. For the fastest professional version, later download the best images, convert them to WebP, and place them in a local `assets` folder.
